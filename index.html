Cloud & Systems Engineering Reference
Active Topic Reference
1. Core Config & Context
Config
View current project configuration & active account
gcloud config list
Set active project ID & default region
gcloud config set project qubere-demo
gcloud config set compute/region us-west1
Authenticate Application Default Credentials (ADC)
gcloud auth application-default login
2. Cloud Run Services & Jobs
Serverless
List all running Cloud Run services
gcloud run services list --region=us-west1
Deploy container to a Cloud Run service
gcloud run deploy qubere-tms-demo \
  --image=us-west1-docker.pkg.dev/qubere-demo/cloud-run-source-deploy/qubere-demo-tms:latest \
  --region=us-west1 \
  --service-account=qubere-app-runtime@qubere-demo.iam.gserviceaccount.com
Execute a Cloud Run Job on-demand
gcloud run jobs execute qubere-db-backup-demo --region=us-west1
3. Cloud Build & CI/CD
Build Pipeline
List all automated build triggers
gcloud builds triggers list --region=us-west1
Manually trigger a build execution
gcloud builds triggers run qubere-tms-demo --region=us-west1 --branch=main
View recent build executions & stream logs
gcloud builds list --region=us-west1 --limit=10
gcloud builds log <BUILD_ID> --region=us-west1
4. Cloud SQL (Postgres)
Database
List Cloud SQL instances & IP addresses
gcloud sql instances list
Create an on-demand database backup
gcloud sql backups create --instance=qubere-demo-instance --description="Pre-deploy backup"
Connect directly via Cloud SQL Proxy CLI
gcloud sql connect qubere-demo-instance --user=postgres --database=qubere_db
5. Compute Engine (VMs)
Virtual Machines
List all VM instances and running state
gcloud compute instances list
Stop instance (halts compute billing)
gcloud compute instances stop delete-after-datadump --zone=us-west1-b
Delete VM instance permanently
gcloud compute instances delete delete-after-datadump --zone=us-west1-b --quiet
6. Storage & Artifacts
Assets & Registry
List GCS buckets & backup files
gcloud storage ls
gcloud storage ls gs://qubere-demo-db-backups/
List Artifact Registry container images
gcloud artifacts docker images list us-west1-docker.pkg.dev/qubere-demo/cloud-run-source-deploy
